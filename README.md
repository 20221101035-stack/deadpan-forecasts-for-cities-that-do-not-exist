A program that writes one original line to /output/entry.txt: a deadpan weather forecast for the invented city of Quillmarsh — 23 degrees, with rain falling upward at 14 kilometres an hour, so umbrellas are useless and hats are strongly discouraged.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
